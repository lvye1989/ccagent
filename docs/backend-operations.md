## 数据页与结构校验

后台数据页显示连接、Schema、运行账户、检测时间、必需表及迁移版本；连接串和数据库密码不回传。读取实际迁移日志的时间戳和摘要，逐项比较源码中的四个迁移，不能仅凭数量相等声称结构就绪。22 张必需表包括迁移日志；缺少必需表或出现未纳入版本的表均会提示核对。

迁移校验清单由当前 Drizzle 日志、SQL 和表定义生成。默认 Schema 使用原始 SQL 摘要；隔离测试 Schema 按测试夹具采用的同一替换规则计算精确摘要，不能把任意摘要当成匹配。服务端携带摘要计算模板用于核对，不执行模板 SQL，也不自动迁移、修复日志或建表。浏览器构建产物未包含该服务端模块。

数据完整时，以一个只读事务快照读取余额、冻结金额、用户、Key、订单、退款、调用、用户任务、流水、审计、路由、成本和未删除临时文件数量。任务按用户和任务编号分组。缺表时返回不可读取状态，业务数量为 `null`、待办为空，页面显示“暂不可读取”；不会把读取失败显示成零。迁移摘要冲突但表仍完整时保留真实统计，同时显著显示结构警告。

待办按服务端实际权限提供，每类最多展示最早五条：待完成订单；已冻结、提交中及待核对退款；达到核对期限的进行中或待对账调用。后者可跳转至 `overdue=true` 筛选，继续组合用户、服务、任务、分页和导出条件。该参数仅用于调用与任务列表，只接受 `true` 或空值。界面只读，资金处理仍走原服务端业务流程。

最近维护记录只展示实际审计时间和受限结果，不返回原始审计元数据；没有记录时明确显示“尚无执行记录”。测试中的维护记录为合成数据，不能证明正式 Cron 已启用或成功执行。

## 八组设置与时间显示

设置分为通用、认证、支付、邮箱、存储、AI 服务、后端数据、余额与计费八组。可保存字段继续限制为原有五项：客服邮箱、开放充值、最低充值分、最高充值分、美元结算汇率；保留版本冲突检查、环境变量只读优先级、保存与错误反馈。邮箱密码登录、注册验证和 1.3 倍收费规则不能在表单中关闭或改写。

支付组显示经过校验的 HTTPS 网关来源、商户及密钥配置状态、支付宝、可选渠道格式及固定通知/返回地址；地址从服务端有效 HTTPS 认证地址生成，不展示网关凭据、路径或查询中的秘密。邮箱仅显示合法发信域名和配置状态；后端显示 Schema 与连接上限；存储、AI 凭据只显示配置状态或数量。配置存在不等于真实邮件、支付、存储或模型已联调成功。

成本表单现可选择已有的全部十类计量项，包含图像、音频、视频输入及音频输出。此项没有增加生图服务或调用 OpenAI；生图仍等待此前凭据来源选择。

共享表格的明确日期列统一显示北京时间，兼容 PostgreSQL 带偏移时间字符串及 Date 对象，避免筛选按北京时间而列表显示 UTC。普通文本和无效日期保持原样，原始数据及 CSV 时间值不被展示格式改写。
