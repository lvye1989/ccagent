# 管理员备用路由与用户价格确认（2026-11-07）

此项完成已有服务的一级备用切换，沿用真实登录、个人 CCAGENT Key、整数微元账本和私有结果存储。它不增加 OpenAI 生图接口，不自动改用用户的个人供应商 Key。正式供应商配置、价格、支付与最终安装包仍按 [完整需求核对](goal-audit.md) 分别验收。

## 管理和用户操作

管理员在“编辑服务网关”载入主路由，选择“启用一级备用”，填写另一条路由编号后保存。备用须为同服务类型、同协议的路由；开放主路由时，备用还须已经开放且具备凭据、有效成本和必要汇率。服务器拒绝自身引用、缺少目标、不兼容和循环关系。已有 `fallbackRouteId` 不会自动开启新增的 `fallbackEnabled`。

用户在 Web 官方服务设置、桌面引导或 CLI 查看主、备用价格后，主动开启“允许使用已确认价格的管理员备用路由”。默认关闭，与官方辅助服务开关独立。CLI 使用 `ccagent account fallback --enabled true` 显示费率、来源、汇率、1.3 倍率及冻结规则，并等待明确确认；关闭使用 `--enabled false`。这些目录和授权操作不调用收费模型。

确认绑定当次目录修订号和价格指纹。指纹包含路由/供应商/模型/协议、公开成本及版本、币种、汇率、倍率、计价策略和输入/输出/图片限制。刷新发现目录变化后，客户端撤销新调用的旧授权，用户须重新核对并开启。保存时在账户文件事务内再次核对修订号与目录，旧窗口不能沿用旧价格确认。有效的既有角色及主动清空的辅助选择保留。

## 一次业务调用的边界

网关在冻结前同时验证主、备用配置、价格指纹、输入限制、图片归属和两份协议请求。只创建一笔业务调用和一次冻结，金额为主、备用授权上界的较大值，最低一微元；预算不等于实际账单。主路由按原配置完成有限重试后，只有连接失败或 429/5xx 且尚未接受成功响应时，才尝试已确认的备用。

一级备用共用主路由原有的整体超时预算，单次请求还受所在路由超时限制；预算耗尽不会另开备用调用。备用自己的有限重试仍在同一预算内，不继续跳到第三条路由。4xx、已经接受的 2xx、无效成功内容或已经开始的流式输出均不触发另一路由。流式中断继续按原用量核验规则处理，不能用备用生成另一份结果掩盖未知状态。

按最终成功路由的实际用量、成本、汇率和实际开始尝试时的峰谷时段结算一次，释放未用余额。内部失败与额外尝试成本由平台承担，超出授权上限的异常差额也由平台承担。调用记录保存两路不可变价格快照，以及 `executedRouteId`、`executedPriceId`、`executedPriceVersion`、`executionStartedAt`、`fallbackUsed`、尝试数和平台重试成本标记。若冻结后、尚未发出请求时发现价格日历过期，则释放全部额度，实际执行路由为空，不伪造执行记录。

结果未知时保留待核验冻结，由原维护规则处理；不能另建业务调用反复收费。客户端日志保存原主、备用价格确认，即使之后关闭授权或目录调价，旧调用也仅按原标识、请求和价格快照恢复或重放，已完成重放不再访问供应商。响应及重放均提供实际路由和备用状态。用户明细、后台查询和导出增加“实际执行路由”“使用备用”；从未派发的调用不推断成已执行。
