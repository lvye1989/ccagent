# 在后台统一配置模型服务

管理员在 `/admin/routes` 完成供应商 API Key、接口地址、模型、调用限制、成本版本、结算汇率、允许域名和开放状态的管理。日常新增和更换供应商不需要修改 Vercel 环境变量或重新部署。后台服务仍需现有数据库与认证基础配置。

## 使用顺序

1. 如使用内置名单之外的供应商，在同页添加精确上游域名；只填写主机名，不含协议、路径或通配符。美元计价时在同页配置结算汇率。
2. 新建路由，填写供应商、协议、模型和接口地址；聊天填写 API 基础地址，决策、搜索、语音填写完整接口地址。
3. 在“供应商 API Key”输入真实供应商 Key，先保存为暂停开放。空白保留现有凭据，明确移除会暂停路由。
4. 在同页成本编辑器配置公开价格并追加成本版本。免费项目也需明确填零；收费倍率由平台统一计算，不要再次乘入成本单价。成本保存期间路由表单锁定；若其他管理员已更换模型，旧页面提交会被拒绝，应重新载入后核对。
5. 可准备连接检测。只有明确发起真实检测才请求上游并产生供应商费用；查询原检测不会另发一笔请求。
6. 完成核对后开放路由，按需设置平台默认服务。既有用户选择不会被默认推荐覆盖。

## 存储与授权

凭据由服务端使用 AES-256-GCM 加密。加密密钥通过 HKDF 从现有 `AUTH_SECRET` 按独立用途派生；无需新增部署环境变量。密文以保留配置记录存放在应用现有私有 `settings` 表，不新增公开数据接口。

关联数据绑定路由编号、供应商和规范化接口地址。更换供应商或地址时需重新绑定 Key；失效的后台凭据不会自动回退到旧环境变量。查询、页面、CSV 和审计只提供配置状态及操作元数据，不返回 Key 或密文。密钥不写入 URL、浏览器存储或前端路由数据。

路由和网关配置写入均检查业务权限 `routes.write` 与同源请求。域名管理只接受精确公开域名；新增域名须通过公开 DNS 地址检查，实际自定义上游连接固定已验证 IP，并校验证书及拒绝重定向，避免访问本机、内网或云元数据地址。

旧 `CCAGENT_PROVIDER_*` 配置仅在内置或原服务器信任的上游域名上保持兼容；后台新批准的域名必须重新录入绑定该路由的 Key。保存后台 Key 后优先使用后台配置，明确删除后不会重新启用旧环境 Key。后台保存的结算汇率优先于历史 `SETTLEMENT_USD_CNY` 默认值，既有调用保留原价格及汇率快照。

## 维护边界

数据库备份包含凭据密文，恢复时还需要匹配的服务端根密钥。轮换 `AUTH_SECRET` 后，旧供应商密文将无法解密，应重新在后台录入供应商 Key；不要把根密钥与数据库备份放在同一个公开位置。

页面配置完整不等于供应商账户已开通模型。供应商模型权限、余额、地域、响应协议及价格仍须分别核对。自动化回归使用合成 Key 和隔离数据库，不代表真实供应商扣费验收。

数据库写入回归共享实例级管理锁，应以 `--test-concurrency=1` 串行执行，并与浏览器夹具的写入阶段错开。Qwen 隔离检查保留既有生产行指纹，同时单独核对测试期间新增的定时维护审计，避免将正常维护误判为测试修改业务数据。
