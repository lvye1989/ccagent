# Excalidraw 建筑与城市设计绘图

白板直接使用管理员在服务网关配置并开放的图像生成服务。用户无需选择模型、供应商、地址或填写供应商 Key；历史 `whiteboardDesignImage` 个人配置、已保存的个人图像凭据、`IMAGE_EDIT_*` 和项目 `.env` 中的直连配置不参与白板调用。旧客户端保存个人模型设置的请求会被拒绝。

## 使用

打开左侧 Excalidraw，进入建筑与城市设计面板，填写要求并生成。没有图片时自动文生图；导入原图、勾画或添加参考图后自动图生图。参考图可以独立使用，无需先导入底图。原图、勾画和参考图合计最多 16 张。

用户仍可选择输出宽高比、1K/2K/4K 分辨率和当前服务支持的背景参数。这些是生成要求，不是模型连接设置。

打开面板和开始新任务时，后端使用当前已绑定的个人平台 Key 读取最新 `/v1/models`。这不会新建 Key，也不会修改当前主模型、Qwen 读图角色、全局辅助开关、备用偏好、已保存价格或账户配置版本。读取到的图像路由与价格构成仅用于本次图像调用的客户端快照，因此管理员新开放服务后用户无需手动刷新目录。

后台设置了图像默认路由时，后端优先使用它。输入模式不匹配时，选择同系列对应的文生图或图生图路由；管理员未开放对应路由则明确报告服务暂未开放，不自动换其他系列。后台没有指定默认时，按已开放路由编号稳定排序选择基准及匹配模式。初始模式匹配不是失败后的备用重试；实际生成失败不会换模型重发。

没有已绑定平台 Key 时显示账户服务暂不可用；没有当前模式的可用服务时显示图像生成服务暂未开放。界面不会要求用户填写供应商连接信息，也不会回落个人 Key。

## 功能和文件限制

Kie GPT Image 2.5 支持 Flare/Sunburst 两个系列的文生图和图生图。提示词最多 20,000 字符；宽高比支持 `auto`、`1:1`、`3:2`、`2:3`、`4:3`、`3:4`、`16:9`、`9:16`、`21:9`、`27:16`、`16:27`、`9:8`、`8:9`。最后四种仅支持 1K。1K 背景可用 `transparent/opaque/auto`，2K/4K 省略背景字段。每次生成一张图片。

每张输入最大 30 MiB，单边最多 8192、总像素最多 16,777,216。高清原图和参考图逐张写入账户与工作区隔离的临时附件库，30 分钟后清理，总量最多 480 MiB。临时附件不属于永久白板历史；画布保留压缩底图与用户勾画。

生成结果使用独立限制：64 MiB、单边 8192、总像素 67,108,864。下载保留原始尺寸及透明背景；大图放入画布时生成保留透明度的缩小 PNG 预览，白板总量仍限制为 10 MiB。保存失败不会丢弃已返回结果的预览与下载入口。

## 调用与恢复

应用自动上传当前账户的私有图片，使用 `POST /v1/images/tasks` 创建任务，通过 `GET /v1/images/tasks/{id}` 查询，并经账户鉴权的 `/api/files/{id}` 下载结果。供应商 Key 仅保存在后台。

后台在派发前根据实际输入确定模式并冻结选中的路由；渲染器不提交 `model` 或 `generationMode`。逻辑输入指纹、上传 UUID、提交屏障和平台任务 ID 保存为账户隔离的回执元数据。相同请求编号重入复用原任务，改变输入不能复用原编号。提交结果未知时仅查询，不再次创建收费任务。

停止仅停止本地等待，不能取消供应商已接受的任务。通过“继续查询原任务”恢复，刷新和重启后也不需要重新上传或生成。成功和明确失败的本地回执在 24 小时后清理；未知回执保留以供核对。结果恢复还受平台私有文件有效期限制。

主对话模型仍为 DeepSeek；Qwen 的 `image` 读图角色与图像生成 `imageGeneration` 相互独立。

## 验证

本地 HTTP fixtures 覆盖遗留个人配置和环境不干扰、默认路由及同系列模式配对、无可用服务、自动目录更新且账户配置不变、私有上传、16 图/20k、参数限制、单次提交、断线与停止恢复、账户/工作区隔离，以及真实 Web worker 无底图和参考图-only 自动模式。没有真实付费 Kie 调用。

后台配置和平台 API 合同见 [Kie 图像网关](kie-image-gateway.md)。
