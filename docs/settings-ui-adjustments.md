## Key 关联规则

已有云端 Key 只存哈希和前缀，完整内容不能通过 Key 列表取回；没有改为可解密存储。点击“连接官方服务”时，本地后端优先复用当前账户与服务来源的有效加密绑定；没有绑定时，通过现有账户 API 显式创建“CCAGENT 应用专用 Key”，校验目录后写入 DPAPI 存储。网页只收到配置状态和前缀，不接收生成的完整 Key。

GET、页面打开或单纯登录不会创建 Key。跨进程连接锁及配置修订检查避免并发重复创建或覆盖手工修改；失败会尝试用原会话撤销本次新 Key 并恢复原配置。创建或撤销结果不明时不自动重试，保留用户中心核对和手工关联途径。

首次关联不会自动开启辅助服务、设置付费默认模型或允许备用调用。用户可在已关联后自行选择服务。
