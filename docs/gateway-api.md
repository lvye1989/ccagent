# CCAGENT 云端网关接入约定

当前为开发实现。云端尚未正式部署；本地 CLI、Web、桌面及共享引擎的统一强制登录仍待接入。不能以本文或接口构建通过作为整套产品已上线的证明。

## 身份和请求标识

网关同时要求有效的 Better Auth 应用会话 Cookie，以及属于该账户的个人 CCAGENT Key。Key 不能替代邮箱密码登录。原生客户端通过登录接口取得签名 Cookie，在 Windows 使用 DPAPI 安全保存；不得保存密码或供应商密钥。

- `Authorization: Bearer <个人 CCAGENT Key>`
- `Cookie: <邮箱密码登录返回的会话 Cookie>`
- `Idempotency-Key: <每次业务调用固定的唯一标识>`，重试相同调用沿用该值。
- `X-CCAGENT-Task-Id: <任务标识>`，同一任务可包含多次不同调用；留空使用本次幂等标识。
- 浏览器请求仅接受应用自身来源。管理、账户与文件写入接口还要求准确的 `Origin`；原生客户端也应按服务地址设置该请求头。

幂等键绑定当前用户、Key、路由、任务及完整请求哈希。修改请求却复用旧键返回 409；已执行的请求不会再次访问供应商。在结果有效期内可重放已完成的私有结果；已过期或未能保存的结果不触发重新执行。

## 服务接口

| 接口 | 请求与用途 |
| --- | --- |
| `GET /v1/models` | 返回已启用且成本、凭据、协议和汇率配置齐全的服务编号、协议、价格版本、公开来源及限制。 |
| `POST /v1/responses` | 原生 Responses 请求，`model` 填平台路由编号；保留工具调用、推理及流式事件。现有 DeepSeek 主模型使用此接口。 |
| `POST /v1/chat/completions` | 原生 Chat Completions 请求，支持图片、函数工具及流式输出；服务器强制请求最终用量。 |
| `POST /v1/decisions` | `model`、`state`、类型化 `questions`；继续调用 Jev Decisions。不会改写成聊天接口。 |
| `POST /v1/search` | `model`、`query`、`max_results`；Tavily 支持 `search_depth`、`topic`、`time_range`，博查支持 `freshness`。域名过滤使用 `include_domains` / `exclude_domains`。 |
| `POST /v1/voice` | `model`、`text`、可选 `voice`；返回归属本账户的短期 WAV 文件编号，不返回供应商下载地址。 |

聊天和 Responses 必须使用模型目录声明的协议。当前收费网关尚未开放 Anthropic/Gemini 协议；配置不能绕过协议就绪检查。本地个人供应商的既有支持与此开发状态分别验收。

Responses 固定为无状态请求：禁止跨调用的 `previous_response_id`、供应商托管会话及后台请求。供应商服务端搜索等额外收费工具尚未定价，不能混入普通 Token 路由；客户端本地工具仍由真实引擎执行权限校验。

## 大文件与结果

直接 JSON 请求上限为 3 MiB。较大请求先使用 `POST /api/files` 申请 `purpose=request` 的私有上传，再按返回的 PUT URL 和完整 `headers` 上传；其中 `x-content-type` 是 Blob 对象类型验证所必需的请求头。上传授权 2 分钟有效，文件默认保留 15 分钟。

上传后调用 `POST /api/files/<id>` 完成大小与类型核对。网关接受 `{ "request_file_id": "<本账户的请求文件 UUID>" }` 读取完整 JSON。不能在同一封装中再附带覆盖字段。

图片也可先上传为 `purpose=image`，在正常图片输入位置填写 `ccagent-file:<图片 UUID>`。服务器校验文件归属、用途、状态和期限后才读取和冻结额度。其他账户的编号返回 404。

语音响应的 `audio.file_id` 通过 `GET /api/files/<id>` 鉴权下载。删除使用 `DELETE /api/files/<id>`。底层存储为私有 Blob，匿名不能读取；过期文件拒绝访问，并由维护任务实际删除。

## 冻结、结算与异常

调用先原子校验账户、Key 和余额，再冻结授权预算；纯文本依据有余量的字节上界与输出限制计算预算，图片等输入按路由上下文上限保守授权。预算不是实际账单。

每次调用记录成本版本、公开来源、币种、汇率、1.3 倍率及价格时间。最终按供应商可核实用量结算并释放剩余额度。供应商异常超出授权预算的部分由平台承担，不临时加扣用户余额；相关差额写入调用记录。

内部重试仅对最终成功响应向用户结算一次，额外尝试由平台承担。流式连接取消后，服务器会在原超时范围内继续读取最终统计；已有可核实用量时按统计结算，无法核实时转为待核验。24 小时后仍无法核实的冻结由维护任务释放，不估算 Token 扣款。

`X-CCAGENT-Call-Id` 返回数据库调用编号。典型状态包括 401 未登录、403 Key/权限无效、402 余额或额度不足、409 幂等冲突/处理中、410 结果过期、502 上游未完成。发生网络错误后应先查询调用状态，不自动更换幂等键重复发起。

## 定时维护

`cloud/vercel.json` 配置每分钟调用 `/api/system/maintenance`，处理过期调用、私有文件清理和七支付订单补偿。该接口使用独立 `CRON_SECRET`，个人 Key 和应用会话不能替代系统身份。接口实现支持重复执行；资金操作按数据库唯一引用防止重复结算。退款未知结果不进入自动重发流程。

该定时配置在部署并配置密钥后才会实际运行。目前源码和数据库隔离检查已通过，尚未认定线上定时任务已启用。
