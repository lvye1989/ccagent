# 后台真实连接检测（2026-11-07）

后台“编辑服务网关”新增真实连接检测，使用服务器已经保存的路由及现有协议适配器。配置齐全和真实请求结果分别显示，检测通过不自动开放服务，也不替代正式供应商、账单和大陆网络验收。OpenAI 生图仍等待用户选择凭据方式。

## 管理员操作

载入路由后点击“准备连接检测”，查看已保存供应商、模型、协议、成本版本、公开价格来源、汇率和预计公开成本上界。管理员明确勾选费用确认后，才可点击“发起真实检测”。修改路由后应先保存，再重新准备；暂停中的路由也可检测，但仍须具备合法主机、服务端凭据、有效价格绑定及必要汇率。

每次检测只发起一次供应商调用，最长为已保存路由超时与 30 秒的较小值，不执行内部重试或备用切换。检测固定使用简短文本、内置 64×64 图片、一个类型化 Jev 问题、基础搜索的一条结果，或“连接测试。”的 WAV 合成；不能从客户端指定额外提示、请求体、地址或密钥。语音下载仅接受既有 OSS 主机校验及 HTTPS，核对 WAV 后丢弃，不生成用户结果文件。

检测的供应商成本由平台承担，用户扣费为零，不创建个人 Key、用户调用预留单或资金流水。预计成本使用与普通网关相同的授权上界与精确计价逻辑；最终保存供应商可核实用量、实际调用开始时的成本/峰谷时段与汇率快照。估算不是供应商账单保证，超估算差额也由平台承担。

结果显示检测编号、北京时间、耗时、上游 HTTP 状态、可核实用量及公开成本。明确的上游拒绝显示失败；超时、网络中断、无效结果或用量无法核实显示“结果待确认”，不能将其描述成免费成功。已知欠费/模型未开通代码保留可操作提示，原始供应商正文、错误文本、任意错误代码、密钥和音频下载地址均不返回或写入审计。普通用户及失效/禁用账户不能访问检测。

刷新后可重新准备并查看最近检测及原编号，费用确认恢复为未勾选；查询原编号不再请求供应商。较早配置的检测会明确标记，不能作为当前配置结果。结果未知时先核对供应商记录，再主动决定是否重新检测。

## 接口与审计

| 接口 | 行为 |
| --- | --- |
| `GET /api/admin/routes/test?routeId=<编号>` | 免费准备：返回固定测试说明、成本估算、确认指纹和最近检测；不访问供应商。 |
| `GET /api/admin/routes/test?routeId=<编号>&testId=<UUID>` | 查询该路由原检测结果；要求当前 `routes.write` 权限。 |
| `POST /api/admin/routes/test` | 严格接受 `routeId`、`testId`、`confirmationFingerprint`、`confirmPlatformCost=true`。新检测返回 202，完成结果重放返回 200。 |

写入接口逐次验证真实登录、权限和准确来源。确认指纹绑定已保存路由、价格/汇率/限制、固定测试请求及模板版本；变化后返回 409，未确认费用或额外字段返回 400，均在派发前拒绝。新检测编号、操作者、路由和确认指纹一并绑定；相同请求只查询原结果，不重新执行。另一编号在该路由检测未结束时被拒绝。

采用已有不可变审计表追加 `routes.test.start` 与 `routes.test.result` 两个事件，通过检测编号关联，不修改历史审计。短事务只负责验证与认领，上游 HTTP 和结果读取在事务外执行；Next.js `after()` 保持响应后的有界工作。没有结果事件的旧记录五分钟后按“待确认”展示，相同编号仍不重发；新检测仍需要主动准备及费用确认。没有新增数据库表或迁移，用户账本规则保持原状。

`publishedRoute` 保留普通收费接口的开放检查；只有受管理员权限保护的检测使用共享选择器验证暂停路由。协议准备、计量和金额计算复用 `prepareUpstream`、`measuredUsage`、`maximumQuantities`、`quoteDefinition`，不另造模拟业务引擎。事务与连接继续使用现有受限角色、TLS 和有界连接池，参见 [Supabase 连接文档](https://supabase.com/docs/guides/database/connecting-to-postgres)。
