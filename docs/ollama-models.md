# Ollama 本地大模型接入

打开“设置 → 模型接入 → 接入 Ollama”，填写服务地址，读取已安装模型后选择要接入的模型，保存。配置与 CLI 共用；保存后首页和对话的模型列表中显示 `Ollama · 模型名称`。可以勾选设为新对话默认模型，已有对话仍可单独选择模型。

| 设置 | 填写方式 |
| --- | --- |
| 服务地址 | 本机默认为 `http://127.0.0.1:11434`，也支持填写带 `/v1` 的地址或自行部署的局域网服务 |
| 模型名称 | 通过“检测已安装模型”选择，也可手工填写与 `ollama list` 一致的完整名称和标签 |
| 配置名称 | 应用中的唯一标识，多个模型使用不同名称 |
| API Key | Ollama 本地入口无需填写 |
| Token 限制 | 可选；根据本地模型及 Ollama 的实际上下文窗口设置 |

保存后点击模型卡片的“测试连接”，应用会发送简短测试消息。对话及 Agent 使用现有引擎、工具和权限规则；Agent 任务需要所选模型支持工具调用。嵌入模型用于向量化，不能作为对话模型使用。

关闭思考时使用 Ollama 的 `none` 参数；启用时采用所选模型的默认思考行为，通用的高、中、低强度不会强制发送给不支持它们的本地模型。上下文窗口设置用于应用的上下文管理；修改 Ollama 实际上下文容量需同时配置 Ollama 服务或 Modelfile。

请求直接发送到填写的 Ollama 服务。本机模型使用本机算力，不消耗 CCAGENT 平台余额。转换已有配置为 Ollama 时会清空该模型的凭据引用和自定义请求头，其他配置保留。

## 服务未启动或没有模型

- 已安装 Ollama：打开 Ollama 应用，或在终端执行 `ollama serve`。如果已有服务正在运行，无需再次启动。
- 尚未安装：前往 [Ollama 官方下载](https://ollama.com/download/windows) 完成安装，再回到应用读取模型。
- 没有模型：先在 Ollama 中下载适合本机内存和显存的对话模型，再执行 `ollama list` 核对完整模型名。应用不会自动下载模型。
- 地址不可达：核对地址、端口及 Ollama 是否已启动。局域网地址还需由部署者配置服务监听和防火墙。
- 测试成功但 Agent 报工具不支持：换用支持工具调用的模型；普通连接测试不等于工具能力测试。

## 开发实现

模型发现使用 `GET /api/tags`，实际对话使用 `/v1/chat/completions`。应用在用户设置中保存 `provider: "ollama"` 和 `protocol: "openai-chat"`，使用现有模型 Profile、流式输出和工具往返处理。读取模型列表有超时及大小限制，不携带其他模型凭据，也不会自动拉取模型。

官方参考：[列出模型](https://docs.ollama.com/api/tags)、[OpenAI 兼容接口](https://docs.ollama.com/api/openai-compatibility)、[工具调用](https://docs.ollama.com/capabilities/tool-calling)。
