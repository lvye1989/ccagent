## 按用户指定路径保存

打开 [设置 → 权限与执行](http://127.0.0.1:4174/?view=settings&setting=execution)，在“额外授权的文件目录”中每行填写一个完整目录，或点击“选择文件夹并加入”，最后点击“保存设置”。文件工具随后可以在这些目录读写。支持中文、空格、带双引号粘贴的绝对路径和尚未创建的子目录；保存授权本身不创建目录。清空并保存可撤销这里的授权，已生成文件保留。可信项目或策略中另行配置的目录仍遵循各自设置。

示例：先授权 C:\Users\Windows11\Desktop\交付文件，再要求“生成 Word，保存到 C:\Users\Windows11\Desktop\交付文件\报告.docx”。模型需将完整路径填写到文件工具的 file_path 或交付/转换工具的 output_path。目录授权与工具审批、Windows 文件权限共同生效。

本次修复了文档转换无法创建尚未存在的授权目录的问题，并补齐 Web 授权入口和即时生效/撤销。实际 HTTP 测试验证了现有会话在授权后可以写入、撤销后立即被拒绝，原文件不被删除。路径专项同时验证了相对路径、多级目录、覆盖保护、父路径为文件时的错误，以及 junction 越界拒绝。
