# Web 自定义功能验证

验证日期：2026-10-29（北京时间）。

工作区文件及「+」工具：`src/scripts/webFilesChecks.ts` 由 `test:web` 调用，使用真实 HTTP 服务验证代码、无扩展名文本、HTML 字面内容、图片、PDF、音频、未知二进制、DOCX 正文、XLSX 稀疏单元格、PPTX 正文、超长文本截断、250 项分页、筛选、附件上传下载、媒体 Range、越界/目录链接拒绝与过期工作区拦截。`test:web-customization` 使用本地模型协议替身和真实 QueryEngine，验证菜单的技能/自定义命令展开、关闭技能过滤、上传附件经 Read 工具实际读取，以及切换目录后命令隔离。它不证明外部搜索供应商的可用性。

`scripts/test-web-ui.mjs` 还验证删除搜索后保留历史列表、首页右侧目录及各格式查看器、Office 表格字面渲染、文件引用卡、聊天/工作/后续对话中的工具菜单、键盘和点击外部关闭、系统文件夹入口、上传字节、技能与 WebSearch 要求随消息提交、计划模式、插件入口，以及发送失败保留引用。浏览器视觉检查仍受下述授权限制；当前上下文没有「+」菜单参考图，不能据此声称已核对参考图外观。

工作文件夹选择器：新增目录浏览、路径跳转、常用位置/磁盘、最近项目、名称搜索、隐藏目录、空目录选择及 Windows 系统选择器。`test:web` 验证真实目录列表及中文/空格路径；`test:web-customization` 实际执行相对路径 Read，确认命中新选择的目录，并验证资料空间范围、项目 Agent 隔离与切回后会话恢复。`scripts/test-workspace-picker-ui.mjs` 在离线 DOM 中验证选择/确认、上一级、双击、搜索、错误恢复、取消、原生选择器返回/取消/失败、切换锁定及焦点恢复。Windows 原生组件通过 `powershell.exe -NoProfile -STA -File web/select-folder.ps1 -ValidateOnly` 加载检查；系统对话框外观尚未经人工核验。
