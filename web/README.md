# CCAGENT Web

选择工作文件夹：点击首页输入框旁的文件夹或侧栏项目名，可浏览常用位置、磁盘、最近项目，搜索子文件夹，单击选中、双击进入，再点击“在此文件夹工作”。支持路径粘贴跳转、空文件夹和显示隐藏目录；Windows 可点击“选择本机文件夹…”使用系统选择器，系统窗口取消后工作区保持不变。切换后会重载所选项目的模型、技能、Agent、MCP、资料和会话，任务的相对路径以该目录为准。运行中的前台任务、后台 Agent 或团队结束后才能切换。

## 自定义、模型与知识库

- `?view=agents`：点击“创建 Agent”，描述需求生成可编辑角色，或直接填写名称、使用场景与工作要求；保存为用户/项目 `.ccagent/agents/*.md`。自定义 Agent 可再次编辑，也可单独启停。
- `?view=mcp`：点击“添加 MCP”，输入服务 URL、标准 `mcpServers` JSON 或带有具体包名/命令的需求，解析后核对并“添加并连接”。支持 stdio / HTTP / SSE，连接与工具发现状态会持续更新。
- `?view=skills`：支持导入单个 SKILL.md，或通过“加载技能目录”导入完整目录（含 scripts、references 等）。逐项启停状态持久化并同时控制模型发现、Skill 工具和 `/技能名` 调用。
- `?view=settings`：通用、模型接入、权限与执行分类设置。LLM 支持 OpenAI 兼容 Chat Completions / Responses、Anthropic 兼容 Messages、Gemini；保存后在首页/对话模型选择器使用，“测试连接”发送简短请求验证实际调用。凭据保存在用户 CCAGENT 目录的 `web-secrets.env`，settings.json 仅保存环境变量引用，CLI 启动时同样加载。
- `?view=teams`：编辑/生成团队角色、启停团队配置或总开关。首页输入框下方可选择“不启用团队”“根据任务自动组队”或已启用的角色团队；现有对话也可切换。后台成员完成后服务会自动继续汇总。运行中的团队完成前不能切换工作区或更改团队配置。
- `?view=library`：“外接 RAG 知识库”配置可选 Bearer 密钥、集合、topK，并可启停和测试检索。通用检索契约：向自有端口 POST `{ "query": "问题", "topK": 5, "collection": "可选" }`，返回 `{ "results": [{ "text": "来源片段", "source": "来源地址", "title": "标题", "score": 0.9 }] }`。对话与 CLI 可用 `KnowledgeSearch` 检索已启用连接；其他知识库产品可用适配服务对接此端口。

验证：`npm.cmd run typecheck`、`npm.cmd run test:web`、`npm.cmd run test:web-customization`。新增集成测试使用隔离的临时工作区/用户目录、本机模型及 RAG 测试服务和真实 stdio MCP 测试进程，验证持久化、CLI 联动、团队实际执行及关闭拦截，不会改写个人配置。

本地 Web 工作区。页面文件位于本目录，服务入口是 `src/entrypoint/web.ts`，并通过现有 `ccagent` 命令启动。

```powershell
npm.cmd run build
node dist/ccagent.js web --port 4173
```

打开终端打印的 `http://127.0.0.1:4173`。开发时可运行 `npm.cmd run web:dev`。从其他项目目录使用已安装的命令时，运行 `ccagent web --workspace <项目目录>`。

Web 与 CLI 复用 `QueryEngine`、权限规则、模型配置、工具和会话存储。会话在服务端运行，浏览器通过同源 HTTP API 和 SSE 接收进度；关闭标签页不会自动取消任务。任务审批由 Web 对话框处理，当前只提供单次允许或拒绝。服务仅监听本机回环地址。文件历史模块是进程级状态，因此当前 Web 服务一次只运行一个前台任务。若会话目录暂时无法写入，当前进程中的对话仍可继续，界面会提示新增内容无法在重启后恢复；请修复目录访问权限后重新启动服务。

输入框里的模型菜单提供 DeepSeek 与 Qwen Plus。新会话使用首页选中的模型；已有会话在任务空闲时可直接切换，选择会写入会话记录，CLI 和 Web 共用对应的模型配置。Qwen Plus 使用 `qwen-plus` 模型和 `DASHSCOPE_API_KEY` 环境变量；现有配置可通过 `ccagent init` 合并更新。麦克风按钮打开语音对话：浏览器识别讲话、自动发送、朗读回复，再继续聆听。语音依赖浏览器的 SpeechRecognition、SpeechSynthesis 和麦克风权限；页面不会把音频传给 CCAGENT 服务端。

在 Web 对话里由 BrowserSearch 打开的网页显示于右侧网页侧栏，不调用系统默认浏览器。侧栏可输入 HTTPS 地址、刷新、复制地址或关闭；助手回复中的网页链接也会在此打开。所有网址仍经过 BrowserSearch 已有的 Jev/权限流程（手动输入网址是用户直接操作），CLI 的 BrowserSearch 行为保持不变。页面以沙盒 iframe 显示，因此由网站自身的 `X-Frame-Options` 或 CSP 禁止嵌入的网站可能显示空白；侧栏会保留地址供复制，也不会为此自动弹出新窗口。

左侧“自定义”导航包含插件、技能和 MCP 服务。各页的刷新按钮会重新读取 CLI 共用的插件安装记录、技能目录和 MCP 设置，并同步当前 Web 进程的运行时注册表。MCP 页显示连接状态和已发现的工具，可执行与 `/mcp open`、`/mcp close`、`/mcp reconnect`、`/mcp auth` 相同的操作；服务地址、命令参数和凭据不会返回给浏览器。项目 `.mcp.json` 中尚未批准的服务只显示提示，不会自动运行。

“Agents”页展示内置、用户、项目和插件 Agent，可启停或把指定 Agent 的调用要求插入输入框。“技能”页可从本机导入单个 `SKILL.md`，选择安装到当前项目或用户技能目录；同名技能不会被覆盖。导入后的技能与 CLI 共用注册表。首页和对话框都可以选择权限模式，包括“完全访问权益”；该模式会跳过常规工具审批，只应在用户明确需要时选择。

输入框的文件夹按钮可选择最近工作文件夹，或输入已有文件夹的绝对路径。切换会重新载入该项目的设置、技能、Agent、插件和会话，新对话与工具使用选定文件夹。右上角“临时对话”只在当前 Web 进程内存在，不写入会话记录或项目记忆，也不会出现在记忆管理中。

左侧“资料空间”会索引当前工作文件夹中的文档、PDF、Word、演示、表格和图片。支持按文件名搜索，并搜索不超过 256 KB 的文本文件内容；文本可在页面内预览，其余文件可下载。索引跳过 `.git`、`node_modules`、`.ccagent` 等生成目录和明显的凭据文件名。“记忆管理”可回看当前项目的聊天、标记保留或删除记录；标记保留的聊天不会被常规会话保留期限清理。若项目设置把 `cleanupPeriodDays` 设为 `0`，会话持久化整体关闭，保留标记不能覆盖该设置。

左侧“定时任务”可为当前工作文件夹安排一次、每天或每周运行的提示词。任务记录保存在用户的 CCAGENT 目录；到期时 Web 服务会创建普通会话并执行。调度器只在 Web 服务运行时工作，且只执行当前打开的工作文件夹的任务；离线或切到别的文件夹期间到期的任务，会在重新运行服务或切回该文件夹后执行。无人在线时需要人工审批的工具调用会被拒绝，避免任务无限等待；可在任务卡中打开结果对话。

页面保留窄图标栏、项目与最近任务侧栏、居中的首页输入框，以及插件双列列表；侧边栏任务搜索入口及筛选已移除。顶部「聊天／工作」切换输入框布局，两种布局都使用同一个 CCAGENT 任务引擎；切换至聊天布局会恢复默认权限。页面不依赖远端前端服务。

首页和对话页右上角「文件」、首页输入框下方「文件」可打开右侧工作区文件面板；选择新的工作文件夹后会自动打开并重新读取。面板支持子目录、面包屑、上一级、名称筛选、隐藏项和分页，不受资料空间的文档类型限制。代码及文本按字面预览；图片、PDF、音视频使用浏览器原生查看器；Word/PPT/ODF 显示正文，Excel 显示前 20 张表、每表前 200 行及 50 列。Office 原始排版、嵌入对象和其他二进制格式可下载查看。文本预览最多 1 MB，Office 文件预览最多 20 MB；媒体与下载支持分段请求。文件访问限制在所选目录内，拒绝越界链接、Git 内部文件及明显的凭据文件名。

输入框左下角「+」在聊天、工作及后续对话中都可打开工具菜单：添加照片和文件、引用工作区文件、选择工作文件夹、技能和命令、网络搜索、计划模式、插件与 MCP。技能/命令来自当前运行时，关闭的技能不会出现；选择命令后填写参数并发送，调用同一个 QueryEngine。网络搜索选项随消息提交 WebSearch 要求，使用现有检索服务和权限。文件附件每个最大 10 MB，保存至当前工作区 `.ccagent/attachments/<唯一标识>/`，通过可删除的引用卡随消息提交，发送失败时保留；Office 可用正文摘录随引用提交。输入总长度仍限制为 50000 字符。切换工作区会清空旧目录的附件引用。

输入框底栏按参考图采用左侧「+ / 权限」、右侧「模型 / 思考强度 / 麦克风 / 语音或发送」布局；权限选择与实际会话模式连接，完全访问模式显示橙色，不会因为参考图而自动开启。模型显示已配置的真实模型；紫色思考强度读取并保存现有 `effortLevel`，对支持该参数的模型生效。麦克风仅将识别结果追加到草稿，检查后手动发送；黑色波形按钮开启原有语音对话。输入文字或加入附件后，波形按钮切换为发送；运行中的后续对话显示停止按钮。语音输入依赖浏览器 SpeechRecognition 和麦克风授权。

图片附件与 CLI 的 `@图片路径` 使用同一个 `buildUserMessageContent`，含空格路径使用 `@"路径/图片 文件.png"`。图片会作为真实图像块发送，而不是仅发送文件名；`Read` 工具返回的图片也会转换为 Chat Completions 的 `image_url`、Responses 的 `input_image` 或 Gemini 的 `inlineData`，同时保留工具调用 ID 配对。配置的 `modelRoles.image/multimodal/vision` 与 CLI 共用；用户明确为当前会话选择模型时保留该选择。

需要 OCR 或让文本模型读取图片时，可直接要求调用内置 `ReadImage`，或使用内置 `image_reader` Agent。工具复用 `QWEN_* / DASHSCOPE_*` 或 `modelRoles.image` 视觉服务配置，不接收工具参数中的 API Key，不生成临时 OCR 脚本；只允许读取现有工具授权根目录内的图片。视觉请求有 90 秒上限，取消会向底层请求传播；鉴权、文件或输出截断错误会明确返回。CLI 与 Web 共用这两个内置组件，Agent 无需另行安装 Skill。执行失败后，页面会终止未完成工具卡的“执行中”状态，并显示可重试状态。

Plugins / Skills 页面可从左侧图标栏打开，也可使用 `?view=plugins` 或 `?view=skills`。页面读取 CCAGENT 本地插件市场、安装记录和当前工作区的技能列表，与 CLI 使用同一份状态。可搜索插件、添加或更新市场、预览组件后安装或更新插件、按范围启停和卸载插件；卸载时保留插件数据。安装前的预览会检查内容指纹，安装确认短时间内有效。若尚未添加市场，Public 会显示添加入口，参考图中的 ChatGPT 插件不会自动成为 CCAGENT 插件。
